# Tomas Nelson's website

A simple GitHub Pages site and a clean starting point for a new design.

## Preview locally

Open `index.html` in a browser, or start a static server from the repository root:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

The site is plain HTML and CSS, so it does not need a build step or a Node.js server. Edit `index.html` to begin adding your new content.
